# 設定入口とファイルメニューの整理

## 1. 目的・状態・起点

状態: complete（製品実装・自動検証・描画確認済み）。U06着手前の小さいUI変更として、設定を主画面のアイコンから開けるようにし、ファイルメニューを撤去する。

起点は2026-11-13の音声対話によるユーザー要求。ファイルメニューの撤去、主画面への設定アイコン配置、プロジェクトメニューの維持が要求である。配置は上部メニューバー左端に確定した。

## 2. 対象範囲

設定入口の配置、ファイルメニューの撤去、設定・終了actionの参照整理、対応する既存テストと利用者向け文書の更新。

## 3. 対象外

U06の対話UI・Goal制御、設定ダイアログ内部の変更、新しい中断導線、設定保存・接続適用・終了処理の変更。

## 4. 関連文書・着手条件

- [初期UI仕様](../../initial/10-ui-interaction.md)
- [設定の利用手順](../../../docs/settings.md)
- [U05 M2](../../complete/unit_042/INPUT_APPLICATION_INTEGRATION.md)
- [U06親仕様](../../wip/unit_011/GOAL_EXECUTION.md)

着手時の確認では、ファイルメニューは設定と終了だけを持っていた。設定はCtrl+,でも開ける。主画面の閉じる操作はApplicationShellの既存終了処理へ接続されている。

配置は承認済みで、初期UI仕様へ反映した。U06親仕様はplannedのままとする。

## 5. 振る舞い仕様

| 項目 | 仕様 |
|---|---|
| 設定の入口 | 主画面にアイコン形式の設定ボタンを置く。上部メニューバー左端に歯車アイコンを置く |
| ファイルメニュー | メニュー自体を撤去する |
| 終了の入口 | ファイルメニューの終了項目も撤去し、既存のウィンドウを閉じる操作を使う。ユーザー承認済み |
| 他メニュー | プロジェクト・接続・表示を維持する |
| 設定操作 | アイコンとCtrl+,は既存の同じ設定actionを使う。操作可否、モーダル、OK／適用／キャンセルの扱いを維持する |
| 識別 | アイコンにアクセシブル名「設定」を付ける。説明本文や説明用ツールチップは追加しない |

## 7. 設計方針

設定actionをアイコンボタンへ付け替え、既存の設定要求と操作可否を使う。新しい設定管理層や状態は追加しない。Shellが操作可否を設定している終了actionは、参照元も含めて撤去する。

## 8. 対象ファイル

現行コード・テストの参照先と本書のローカルリンクを確認する。既存GUI試験を改訂し、ボタン未実装時の失敗を確認してから実装した。関連35件と全体663件（74.48秒）が成功。ruff format/check、ty、uv lock --check、git diff --check成功。`uv run python scripts/check_package.py`でsdist/wheel生成と新規環境へのインストール、アイコン資材の読込、両入口のGUI起動・終了を確認した。

Qt offscreen描画を画像として確認し、左端の歯車と既存3メニューの配置を確認した。証跡はignoredのtmp/settings-entry/main-left.png。ネイティブの対話操作・DPI変更・実機通信は未実施。差分再レビューで設定actionと操作可否の共用、不要な終了action参照の撤去、説明本文を追加していないことを確認し、修正必須指摘なし。

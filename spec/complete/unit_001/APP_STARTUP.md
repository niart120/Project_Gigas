# U01 アプリ起動とグローバル設定 — 完了した基準点

## 1. 目的と状態

機器・Codexなしでアプリを起動し、設定を編集・保存・再読込して終了できる状態を作った。実装とローカル検証は2026-11-10に完了。2026-11-11の工程再編で、後続へ渡す事実・方針・未検証事項を整理した。文書の改訂で製品を変更したり、既存試験を再実行したりしたものではない。

起点は[初期範囲](../../initial/01-overview.md)、[工程表](../../initial/05-implementation.md)、[開発規約](../../../AGENTS.md)。利用場面は設定なしの起動、GUIでの編集・保存、終了中のTOML手編集後の読込、保存失敗からの再試行、配布物からの起動である。

## 3. 方針だけがある範囲・対象外

| 領域 | 決めた方針・出発点 | U01では実装・検証していないこと | 後続 |
|---|---|---|---|
| 映像 | 共有取得元、プレビューと観測、取得元の選択値を保存 | 機器識別・列挙、取得方式・版・FPS、実画像の取得 | U03、観測保存はU04 |
| 入力 | 初期方式はシリアル、接続先の選択値を保存 | 実デバイス、プロトコル・通信速度、入力・解除・停止 | U05 |
| Codex | Python SDKを優先、モデル・認証方式を設定として保存 | 認証・資格情報・有効モデル、公開機能の成立性 | U02、Goals等はU06以降 |
| 並行処理 | GUIとサービス用ループを分離する初期案 | asyncioサービス、SDK受信、MCP、機器ワーカーの組立てと終了 | U02〜U05 |
| 画面 | M2に将来領域の配置方針がある | プレビュー、会話・計画・回答、ゲーム開始・停止・再開の操作 | 各機能の工程 |
| 保存・記憶 | プロジェクトの配置・原記録・復元の初期設計がある | `project.json`、JSONL、画像、依頼・実行、記憶整理・復元 | U04〜U09 |
| 指示 | 読み取り専用の同梱資材と標準の読込方法 | 製品側の取得・Codex配送、実ツール説明、案内・整理指示 | U02、U04、U06、U09 |

設定保存成功は接続・認証成功ではない。現在のQtワーカーは設定I/O専用で、将来の非同期基盤全体が完成したものではない。`app`からの指示読込もまだ行っていない。exe凍結、インストーラー、PyPI公開、自動更新はこの成果に含めない。

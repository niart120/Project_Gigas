# GIGASの要求

## 目的

GIGASは、汎用AIエージェントにゲームの攻略や操作補助を任せるためのWindowsアプリケーションである。

当面は、一つのゲームについて自然文で目標を伝え、利用者が常時監視・応答しなくても、数時間にわたって攻略を進められることを目指す。エージェントは画面の観測、行動の選択、結果の確認を繰り返し、失敗や停滞への対処も自律的に行う。

利用者は必要なときに進行を確認し、追加指示・停止・手動操作ができる。日をまたぐ中断・再開にも対応するが、当面は一回の継続プレイの実用性を優先する。

## 対象と基本方針

Windows PCに接続した映像取得機器と入力機器を通じて実機ゲームを操作し、当面のエージェントにはCodexを利用する。

ゲーム固有の攻略判断はエージェントに委ね、GIGASは観測・操作・対話・継続利用のための環境を提供する。特定タイトルの攻略手順をアプリに組み込むことを前提にしない。

## 主要な要求

| 要求 | 利用者ができるようにしたいこと |
|---|---|
| 自然文による依頼 | 「ここまで進めて」「この操作を手伝って」と目的を伝え、画面に応じた操作を任せられる |
| 継続プレイ | 一度の応答で終わらない目標を渡し、ほぼ介入せずに数時間の攻略を任せられる |
| 進行の把握と介入 | ゲーム映像、エージェントの応答・計画・実行状態を確認し、追加指示や質問への回答を送れる |
| 活動記録の表示 | エージェントの活動内容と進行状況を、読み取りやすい形で確認できる |
| 映像プレビュー | プレイ中に安定した映像プレビューを確認できる |
| 停止と手動操作 | エージェントの実行と入力を中断し、利用者が同じ機器でゲームを操作できる |
| 中断後の再開 | 会話や攻略資料を引き継ぎ、アプリの再起動後も現在のゲーム画面から続きを依頼できる |
| 攻略情報の蓄積と利用 | エージェントが攻略中に得た知識や進捗を資料として残し、後のプレイで参照できる。利用者も確認・編集できる |
| プロジェクトの管理 | GUIで表示名・作業フォルダーを編集し、既存チャットのID・履歴を保って作業場所を追従させられる。フォルダー欠落時も登録を削除でき、途中失敗後は状態を確認して再試行できる |

## 継続利用で求める品質

数時間動作し続けることに加え、利用者の助けを常態化させずに攻略が進むことを重視する。継続プレイ中も映像や対話を確認でき、停止操作に応答すること。接続や操作に失敗したときは、その状況を把握して再接続・再開へ進めること。

応答性、資源消費、記録容量と、実際の攻略の進み方を実プレイで確かめる。

## 当面の重点

活動記録の読み取りやすさと映像プレビューの安定性を改善し、数時間の攻略を任せられる状態へ進める。具体的な調査事項、改善と検証の順序は[開発計画](roadmap.md)にまとめる。

# グローバル設定

設定は Windows ユーザーごとに `%LOCALAPPDATA%\GIGAS\settings.toml` に保存します。文字コードは UTF-8 です。手で編集するときは、GIGAS を終了してからファイルを開いてください。起動中に編集した値は、アプリからの保存で上書きされる場合があります。

```toml
[capture]
device = ""
width = 1920
height = 1080
fps = 60
preview_fps = 30

[controller.serial]
port = ""

[agent]
model = ""
effort = ""
auth_method = "chatgpt"
```

| 項目 | 意味 |
|---|---|
| `capture.device` | DirectShowの機器パス。空文字は未選択。旧設定の名前・番号は保持するが、接続時に別機器へ自動変換しない |
| `capture.width` / `capture.height` | 要求画像寸法。幅16〜3840、高さ16〜2160の整数 |
| `capture.fps` | 要求取得頻度。1〜120の整数。実際の到着頻度を保証する値ではない |
| `capture.preview_fps` | 表示更新の上限。1〜60の整数 |
| `controller.serial.port` | シリアルポート名。例は `COM3` |
| `agent.model` | 使用したいモデル |
| `agent.effort` | 使用したい推論エフォート |
| `agent.auth_method` | 認証方式。指定できる値は `chatgpt` と `api_key` |

項目を省略すると例の値を使います。空文字は未指定を表します。`auth_method` は方式だけを記録します。API キーやトークンはこのファイルへ書かないでください。

映像の数値項目には小数・真偽値・文字列を指定できません。設定の保存だけでは機器の対応モードを確認しません。機器パスはUSB端子の変更やドライバーの再導入で変わることがあり、その場合は機器を選び直します。

初期開発中は項目名・型・既定値が変わることがあります。更新後にファイルを読めなくなったら、エラーに示された箇所を修正してください。作り直す場合は、既存ファイルを退避すると次回の読込で既定値を使えます。

## 画面から編集する

`uv run gigas`または`uv run python -m gigas`で起動し、主画面右上の「設定…」を押します。設定画面は1つだけ開き、もう一度押すと編集中の画面を前面に出します。

保存先は画面上部で確認・コピーできます。映像取得元、シリアルポート、モデル、エフォートは自由入力で、空欄や改行、前後の空白を許可します。認証方式は「ChatGPT」「APIキー」から選びます。これらは希望値の保存であり、接続や認証は実行しません。

「保存」でTOMLへ書き込みます。設定ファイルがなくても開閉だけでは作成せず、明示的に保存すると作成します。「変更なし」は最後に読込・保存した値と同じ状態、「未保存」はそこから変更した状態です。

「再読込」はファイルを読み直します。未保存の変更があれば「破棄」「取消し」を選びます。設定画面の「閉じる」・×・Escは設定画面だけを閉じます。主画面の×はアプリ終了です。未保存なら「保存」「破棄」「取消し」を選べます。

読込・保存中は編集と次の読込・保存を停止します。途中で閉じる操作をした場合は結果を待ちます。「閉じる取消し」「終了取消し」は閉じる要求を取り消すだけで、進行中の保存は継続します。終了を確定してワーカーを解放する段階では取消しできません。

## エラーが出たとき

主画面の状態欄に失敗した操作を表示し、設定画面の詳細欄に理由と保存先を表示します。詳細は選択・コピーとスクロールができます。

保存に失敗しても入力は残ります。保存先の問題を解消してから「保存」を再試行できます。読込失敗中は編集・保存を停止し、正常に読み込めるまで元ファイルを上書きしません。一時的なI/O障害を解消した場合は「再読込」を使えます。構文や型を直す場合はアプリを終了してからファイルを修正し、再起動してください。作り直す場合も終了後にファイルを退避します。

画面を開けない起動失敗は標準エラーへ診断を出し、終了コード1を返します。通常の終了は0です。読込失敗の画面から閉じた場合も0になります。

## Python から読み書きする

```python
from dataclasses import replace

from gigas.storage.settings import default_settings_path, load_settings, save_settings

path = default_settings_path()
settings = load_settings(path)
save_settings(path, replace(settings, serial_port="COM3"))
```

`default_settings_path()` は保存先だけを返します。テストでは一時ディレクトリ内の `Path` を `load_settings()` と `save_settings()` に直接渡せます。

`load_settings()` はファイルがなければ既定値を返します。ファイルは明示的な保存時に作られます。`save_settings()` は既存の TOML を読み、既知の項目を更新します。変更しない項目とコメントを保ち、変更する文字列を空にする場合も同じ行のコメントを残します。

パスの決定、読込、検証、書込に失敗した場合は `SettingsError` を送出します。既存ファイルの構文や現在の項目が不正な場合、保存を中止してファイルを保持します。一時ファイルの後始末に失敗したときは、例外にその情報も付記します。

# グローバル設定

設定は Windows ユーザーごとに `%LOCALAPPDATA%\GIGAS\settings.toml` に保存します。文字コードは UTF-8 です。手で編集するときは、GIGAS を終了してからファイルを開いてください。起動中に編集した値は、アプリからの保存で上書きされる場合があります。

```toml
[capture]
device = ""
fps = 60
preview_fps = 30
resolution = "full_hd"

[gui]
window_size_preset = "full_hd"
preview_letterbox = true

[controller.serial]
port = ""

[agent]
model = ""
effort = ""
auth_method = "chatgpt"
```

| 項目 | 意味 |
|---|---|
| `capture.device` | 保存済み実機の識別子。空文字は機器なし。設定で「未接続」を明示的に選んで適用すると空にする。メニューの一時停止では保持し、旧設定の名前・番号を別機器へ自動変換しない |
| `capture.fps` | 要求取得頻度。1〜120の整数。実際の到着頻度を保証する値ではない |
| `capture.preview_fps` | 表示更新の上限。1〜60の整数 |
| `capture.resolution` | 取得解像度の要求。`auto`・`hd`・`full_hd`・`wqhd`・`four_k`のいずれか。既定は`full_hd` |
| `gui.window_size_preset` | 表示サイズ。`hd`・`full_hd`・`wqhd`・`four_k`のいずれか。既定は`full_hd` |
| `gui.preview_letterbox` | `true`は比率を保ち黒い余白を付ける「レターボックス」、`false`は表示枠へ合わせる「ストレッチ」。取得画像は変更しない |
| `controller.serial.port` | シリアルポート名。例は `COM3` |
| `agent.model` | 使用したいモデル |
| `agent.effort` | 使用したい推論エフォート |
| `agent.auth_method` | 認証方式。指定できる値は `chatgpt` と `api_key` |

項目を省略すると例の値を使います。機器・シリアルポート・モデル・エフォートの空文字は未指定を表します。`auth_method` は方式だけを記録します。API キーやトークンはこのファイルへ書かないでください。

FPSには小数・真偽値・文字列を指定できません。`preview_letterbox`にはTOMLの真偽値を指定します。解像度や表示サイズの未知の値も設定エラーになります。設定の保存だけでは機器の対応モードを確認しません。機器識別子はUSB端子の変更やドライバーの再導入で変わることがあり、その場合は機器を選び直します。

取得解像度は機器への要求です。「自動」は幅・高さを指定せず、固定値も実際の画像寸法を保証しません。アプリは到着した有効な画像をその寸法のまま共有します。対応する寸法と制限は[映像プレビュー](video.md)を参照してください。旧ファイルの`capture.width`と`capture.height`は未知の項目として保持し、取得寸法の指定には使用しません。

初期開発中は項目名・型・既定値が変わることがあります。更新後にファイルを読めなくなったら、エラーに示された箇所を修正してください。作り直す場合は、既存ファイルを退避すると次回の読込で既定値を使えます。

## 画面から編集する

`uv run gigas`または`uv run python -m gigas`で起動し、「ファイル」→「設定…」または`Ctrl+,`で設定を開きます。設定画面は1つだけ開き、もう一度選ぶと編集中の画面を前面に出します。

設定は次の3タブに分かれます。下部のOK・キャンセル・適用は、開いているタブにかかわらず全タブを対象にします。

| タブ | 項目 |
|---|---|
| 一般 | 設定ファイルの読み込み先、ウィンドウサイズ、プレビュー方式、表示FPS |
| I/O | 映像の機器選択・一覧更新・取得FPS・取得解像度、コントローラーのシリアルポート設定 |
| Codex | モデル、エフォート、認証方式 |

「一般」の設定ファイルのパスは選択・コピーできます。保存先を変更する操作ではありません。「ファイル」→「設定ファイルの場所を開く」から保存先を開けます。

「Codex」のモデルとエフォートは一行で入力します。設定の適用だけでは接続中のモデルを変更しません。現在使える認証方式は「ChatGPT」です。既存ファイルの`api_key`は「APIキー (未対応)」として保持しますが、新しく選択はできません。「ChatGPT」へ明示的に変更した場合だけ置き換えます。シリアルポートも保存値の編集だけで、機器への接続は行いません。未編集の既存値に含まれる改行や前後の空白は保持します。

### 映像の選択と適用

設定を開くと、未接続なら機器一覧を非同期に取得します。取得中は既存の候補を使い、映像を止めません。「I/O」で機器の表示名を選びます。同名の候補には番号を添え、識別子を手入力する必要はありません。一覧更新だけでは未保存の選択や他の項目を変更しません。

機器欄は、設定を開いた時点の取得先を示します。停止中は「未接続」です。前回保存した実機も候補に残るため、選んで適用すれば接続できます。候補にない保存値や選択先は「未確認」「未検出」として区別し、別の機器へ自動変更しません。列挙に失敗しても直前の候補を保持し、「一覧更新」で再試行できます。取得中の追加機器を調べる場合は、先に映像を停止してください。

「未接続」を明示的に選んで適用すると、映像を停止し、保存済みの機器も空にします。未保存の実機を選んでから「未接続」に戻した場合も、適用後は機器なしになります。画面を開いた時点で「未接続」になっているだけでは保存済み機器を消しません。一般の表示設定だけを編集しても、保存済み機器を現在の取得先や空文字へ書き換えることはありません。

取得・表示FPSは15・30・60から選べます。TOMLに保存済みの範囲内の独自値も候補として保持します。取得先・取得FPS・取得解像度の変更を適用すると、必要な保存の成功後、旧取得の終了を確認してから新しい設定で接続します。最初の有効な画像を受け取るまで接続の成功とは扱いません。要求解像度と到着画像の寸法が違う場合も、同じ要求値を繰り返し適用する必要はありません。

表示FPS・ウィンドウサイズ・プレビュー方式は、保存・再読込の成功後に表示へ反映します。これらだけの変更で機器を開き直したり、取得画像を変更したりしません。ウィンドウサイズは主画面の「表示」メニューからも選べます。未保存の編集や処理中の設定がある場合、メニューからの変更は停止します。

### 保存と閉じる操作

| 操作 | 動作 |
|---|---|
| 適用 | 全タブの変更を保存し、必要な映像の開始・切替・停止を行う。設定画面は開いたままにする |
| OK | 適用と同じ処理を行い、必要な保存と映像反映が成功してから閉じる。差分がなければ閉じるだけ |
| キャンセル・×・Esc | 未適用の編集を破棄して設定画面を閉じる。既に適用した保存・表示・接続は巻き戻さない |

保存に失敗した場合は現在の映像と入力を維持し、新しい接続を始めません。保存後に接続だけ失敗した場合は保存値と設定画面を残します。旧機器へ自動復帰せず、編集を変えなくても「適用」で再試行できます。失敗後の再試行成功で、以前のOK操作を理由に画面が閉じることはありません。

保存・映像反映中は下部3ボタンと×・Escによる設定画面の終了を一時停止します。その間も、主画面の映像停止・Codex中断・アプリ終了は操作できます。「接続」→「映像」の停止操作は保存後の未開始接続も取り消し、機器欄を「未接続」に戻します。このメニュー操作は一時停止で、保存済み機器と他の編集内容を保持します。保存処理そのものを取り消す操作ではありません。

設定画面の開閉だけでは設定ファイルを作成しません。起動・ファイルの再読込・アプリ終了時の未保存確認による保存だけでは、映像を開始しません。

### ファイルの再読込とアプリ終了

「ファイル」→「設定を再読込」はファイルを読み直します。未適用の変更があれば「破棄」「取消し」を選びます。読込に失敗した場合は入力を保持し、正常に読み込めるまで保存を禁止します。再読込だけで取得元を切り替えず、機器欄は実際の取得状態に合わせます。

主画面の×はアプリ終了です。未保存なら「保存」「破棄」「取消し」を選べます。取消し可能な終了待ちの間は、主画面の処理表示から「終了取消し」を使えます。進行中の保存は続き、取り消した映像接続やCodexターンを自動再開しません。終了を確定してワーカーを解放する段階では取消しできません。

## エラーが出たとき

主画面に短い失敗通知を表示します。「詳細…」または「表示」→「通知…」から、エラーの説明と診断を開けます。「最近の失敗」には設定・映像・Codex・終了の各発生元で最後の失敗を保持します。通知を閉じたり、その後の操作が成功したりしても履歴は残り、現在の接続状態とは別に扱います。

詳細は選択・コピーとスクロールができます。詳細を開いたまま別の失敗が届いても、表示中の本文を差し替えません。発生元を選び直すか、通知から開き直すと最新の内容になります。エラーの詳細画面は中断・切断を妨げず、開閉だけで再試行や接続を行いません。

ステータスバーは映像欄・Codex欄に対応した位置へ現在の状態を表示します。設定の未適用値や過去の通知は、現在の取得先・接続中のモデルとして表示しません。

保存に失敗しても入力は残ります。保存先の問題を解消してから「適用」を再試行できます。読込失敗中は編集・保存を停止し、正常に読み込めるまで元ファイルを上書きしません。一時的なI/O障害を解消した場合は「再読込」を使えます。構文や型を直す場合はアプリを終了してからファイルを修正し、再起動してください。作り直す場合も終了後にファイルを退避します。

画面を開けない起動失敗は標準エラーへ診断を出し、終了コード1を返します。通常の終了は0です。読込失敗の画面から閉じた場合も0になります。

## Python から読み書きする

```python
from dataclasses import replace

from gigas.storage.settings import default_settings_path, load_settings, save_settings

path = default_settings_path()
settings = load_settings(path)
save_settings(path, replace(settings, serial_port="COM3"))
```

`default_settings_path()` は保存先だけを返します。テストでは一時ディレクトリ内の `Path` を `load_settings()` と `save_settings()` に直接渡せます。

`load_settings()` はファイルがなければ既定値を返します。ファイルは明示的な保存時に作られます。`save_settings()` は既存の TOML を読み、既知の項目を更新します。変更しない項目とコメントを保ち、変更する文字列を空にする場合も同じ行のコメントを残します。

パスの決定、読込、検証、書込に失敗した場合は `SettingsError` を送出します。既存ファイルの構文や現在の項目が不正な場合、保存を中止してファイルを保持します。一時ファイルの後始末に失敗したときは、例外にその情報も付記します。

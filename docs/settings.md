# グローバル設定

設定は Windows ユーザーごとに `%LOCALAPPDATA%\GIGAS\settings.toml` に保存します。文字コードは UTF-8 です。手で編集するときは、GIGAS を終了してからファイルを開いてください。起動中に編集した値は、アプリからの保存で上書きされる場合があります。

```toml
[capture]
device = ""
fps = 60
preview_fps = 30
resolution = "full_hd"

[observation]
resolution = "full_hd"

[project]
last_path = ""

[gui]
window_size_preset = "full_hd"
preview_letterbox = true
show_reasoning = true

[controller.serial]
port = ""
protocol = "ch552"

[agent]
model = ""
effort = ""
auth_method = "chatgpt"
```

| 項目 | 意味 |
|---|---|
| `capture.device` | 使用する実機の識別子。空文字は未接続。設定で未接続を適用するか、メニューで未接続を選ぶと空にする。旧設定の名前・番号を別機器へ自動変換しない |
| `capture.fps` | 要求取得頻度。1〜120の整数。実際の到着頻度を保証する値ではない |
| `capture.preview_fps` | 表示更新の上限。1〜60の整数 |
| `capture.resolution` | 取得解像度の要求。`auto`・`hd`・`full_hd`・`wqhd`・`four_k`のいずれか。既定は`full_hd` |
| `observation.resolution` | agent向け画像のサイズ。`original`（元寸法）・`full_hd`（1920×1080の枠、既定）・`hd`（1280×720の枠）。全画面を比率維持で縮小し、小画像は拡大しない |
| `project.last_path` | 最後に選択したプロジェクトの絶対パス。空文字は未選択。次回起動時に1回だけ復元する |
| `gui.window_size_preset` | 表示サイズ。`hd`・`full_hd`・`wqhd`・`four_k`のいずれか。既定は`full_hd` |
| `gui.preview_letterbox` | `true`は比率を保ち黒い余白を付ける「レターボックス」、`false`は表示枠へ合わせる「ストレッチ」。取得画像は変更しない |
| `gui.show_reasoning` | Historyの公開推論要約を表示する真偽値。既定は`true`。受信は止めない |
| `controller.serial.port` | シリアルポート名。例は `COM3` |
| `controller.serial.protocol` | `ch552`（既定）・`pokecon`・`3ds`のいずれか |
| `controller.serial.baudrate` | 整数の通信速度。省略時はCH552/PokeConで9600、3DSで115200。CH552は9600、PokeConは9600/19200/38400/57600/115200、3DSは9600/19200/57600/115200から選ぶ |
| `agent.model` | 使用したいモデル |
| `agent.effort` | 使用したい推論レベル |
| `agent.auth_method` | 認証方式。対応値は `chatgpt`。旧値 `api_key` は読み書きを維持しますが、接続は未対応です |

項目を省略すると例の値を使います。機器・シリアルポート・モデル・推論レベルの空文字は未指定を表します。`auth_method` は方式だけを記録します。API キーやトークンはこのファイルへ書かないでください。

FPSには小数・真偽値・文字列を指定できません。`preview_letterbox`にはTOMLの真偽値を指定します。解像度や表示サイズの未知の値も設定エラーになります。設定の保存だけでは機器の対応モードを確認しません。機器識別子はUSB端子の変更やドライバーの再導入で変わることがあり、その場合は機器を選び直します。

取得解像度は機器への要求です。「自動」は幅・高さを指定せず、固定値も実際の画像寸法を保証しません。アプリは到着した有効な画像をその寸法のまま共有します。対応する寸法と制限は[映像プレビュー](video.md)を参照してください。旧ファイルの`capture.width`と`capture.height`は未知の項目として保持し、取得寸法の指定には使用しません。

初期開発中は項目名・型・既定値が変わることがあります。更新後にファイルを読めなくなったら、エラーに示された箇所を修正してください。作り直す場合は、既存ファイルを退避すると次回の読込で既定値を使えます。

## 画面から編集する

`uv run gigas`または`uv run python -m gigas`で起動し、主画面上部左端の歯車アイコンまたは`Ctrl+,`で設定を開きます。設定画面はモーダルで、開いている間は主画面のメニューを操作できません。映像取得とCodex受信は継続します。

設定は次の3タブに分かれます。下部のOK・キャンセル・適用は、開いているタブにかかわらず全タブの保存設定を対象にします。Codexの接続・ログイン・準備操作はその場で実行し、設定のキャンセルで取り消しません。

| タブ | 項目 |
|---|---|
| 一般 | 設定ファイルの読み込み先、ウィンドウサイズ、プレビュー方式、表示FPS、推論要約の表示 |
| I/O | 映像の機器選択・一覧更新・取得FPS・取得解像度・観測解像度、コントローラーのポート・プロトコル・通信速度 |
| Codex | Codex App Server、サンドボックス環境、認証、利用状況、接続時の既定値 |

「一般」の設定ファイルのパスは選択・コピーできます。保存先を変更する操作ではありません。隣の「フォルダを開く」から保存先を開けます。読込失敗中や保存中も利用できます。

「Codex」のモデルと推論レベルは一行で入力します。設定の適用だけでは接続中のモデルを変更しません。接続時の既定値はモデル・推論レベルだけです。認証操作は上段の「認証」行にまとめています。対応方式はChatGPTのみです。既存ファイルの`api_key`は自動で書き換えず、認証行の「APIキーからChatGPTに変更」を押して「適用」または「OK」で保存した場合だけ置き換えます。変更操作だけでは接続・ログインを開始しません。キャンセルや保存失敗では保存済みの旧値を保持します。保存前の接続は旧値を使うため、APIキー認証未対応のエラーになります。未編集の既存値に含まれる改行や前後の空白は保持します。

### 映像の選択と適用

設定を開くと、未接続なら機器一覧を非同期に取得します。取得中は既存の候補を使い、映像を止めません。「I/O」で機器の表示名を選びます。同名の候補には番号を添え、識別子を手入力する必要はありません。一覧更新だけでは未保存の選択や他の項目を変更しません。

機器欄は保存する機器を示します。保存機器がAなら、停止中や接続失敗後もAが選択されています。実際の取得状態は主画面下部のステータスで確認します。候補にない機器は保存識別子を表示し、別機器へ自動変更しません。列挙に失敗しても直前の候補と編集値を保持し、「一覧更新」で再試行できます。取得中の追加機器を調べる場合は、未接続を適用してから一覧を更新します。

「未接続」を選んで適用すると、保存する機器を空にして取得を終了します。接続失敗や物理抜去だけでは保存機器を消しません。起動時は自動接続しませんが、無変更やウィンドウサイズ・プレビュー方式・表示FPS・Codex設定の編集を含むOK／適用では、選択中の機器への接続を試みます。入力接続・観測解像度・推論要約の表示だけを変更した場合は、停止中の映像を開始せず、取得中も開き直しません。取得させない場合は未接続を選びます。

取得・表示FPSは15・30・60から選べます。TOMLに保存済みの範囲内の独自値も候補として保持します。取得先・取得FPS・取得解像度の変更を適用すると、必要な保存の成功後、旧取得の終了を確認してから新しい設定で接続します。最初の有効な画像を受け取るまで接続の成功とは扱いません。要求解像度と到着画像の寸法が違う場合も、同じ要求値を繰り返し適用する必要はありません。

表示FPS・ウィンドウサイズ・プレビュー方式は、保存成功後に反映します。取得中の機器は開き直さず、共有画像も変更しません。主画面の「表示」メニューでサイズだけを変更した場合は、停止中の機器を接続しません。設定画面を閉じ、保存処理が終わってからメニューを操作できます。

「観測解像度」は取得解像度・プレビュー表示と独立しています。保存成功後に開始する観測から適用し、生成済みの画像は変更しません。キャンセルでは未適用の編集を破棄します。この設定変更で映像取得やCodexを再接続しません。Pythonの[観測API](recorded-observation.md)でも同じ3種類を指定できます。

「推論要約の表示」は初期オンです。保存成功後にHistoryの公開要約を表示・非表示にし、非表示中も受信します。この項目だけを変更しても映像・入力・Codexを再接続しません。キャンセルと保存失敗では、適用済みの表示を保ちます。

### コントローラーの選択と適用

「シリアルポート」は一覧から選びます。設定を開く操作と「一覧更新」はポートを列挙するだけで接続しません。候補にない保存値や未適用の選択も保持し、別ポートへ自動変更しません。

プロトコルはCH552・PokeCon・3DS S2/T3から選択します。通信速度はプロトコルごとの候補から選び、プロトコルを変更するとその既定値へ戻ります。ファイルで通信速度を省略している場合も既定値を表示し、OK／適用時に具体的な値を保存します。

OK／適用で保存が成功した後に入力接続へ反映します。「未接続」の適用は切断です。同じ実効設定で接続中なら接続を維持し、失敗・停止で接続できていない場合は明示適用で再試行します。接続変更は旧入力を停止・解除し、旧接続を閉じてから新しいポートを開きます。接続するだけでは操作列を開始しません。機器操作は会話のMCP要求を受けて実行します。チャットやプロジェクトの作成は接続条件ではありません。

入力設定を変更した場合と、全設定が実効的に未変更の明示適用だけを入力接続へ反映します。映像・観測解像度・一般・Codexの設定だけを変える適用は入力接続へ影響しません。入力接続と映像の取得条件を同時に変更した場合は両方へ反映します。保存失敗では旧接続を維持し、保存後の接続失敗では保存値と診断を残します。機器を確認して「適用」で再試行してください。

### プロジェクトの選択

主画面の「プロジェクト」→「新規作成」で、既存の親フォルダー内に未作成のフォルダー名を指定します。「開く」は既存プロジェクトのフォルダーを選びます。空フォルダーを既存プロジェクトとして開く操作や、既存データの上書きはできません。選択に成功するとタイトルにパスを表示し、`project.last_path`へ保存します。映像取得は開始・再接続しません。Codex接続中は切り替えられないため、先に「切断」を選びます。

起動時は前回のプロジェクトを1回だけ開きます。読込やロック取得に失敗した場合は通知に詳細を残し、未選択のままチャットを利用できます。起動中に後から設定を保存しても、失敗した復元を自動で繰り返しません。選択後に設定ファイルへの保存だけが失敗した場合は、現在の選択を維持しますが次回の復元先は更新されません。問題を解消後、同じプロジェクトを「開く」から選び直せます。

プロジェクトを選ばなくても会話と観測を記録します。記録場所と会話の寿命は[Codex接続画面](codex-gui.md)を参照してください。プロジェクトの自動復元は、過去の会話を自動再開する操作ではありません。

### 保存と閉じる操作

| 操作 | 動作 |
|---|---|
| 適用 | 全タブの変更を保存し、対象となる映像・入力接続へ反映する。設定画面は開いたままにする |
| OK | 適用と同じ処理を行い、保存成功と接続への反映要求の後に閉じる。接続成功や最初の画像は待たない |
| キャンセル・×・Esc | 未提出の編集を破棄して閉じる。既に提出した保存・適用は取り消さない |

保存に失敗した場合は現在の映像を維持し、開いている設定の編集値を残します。保存後の接続失敗では保存値を保持し、OKで閉じた設定を自動再表示しません。同じ機器をメニューで選び直すか、設定で「適用」を押すと再試行できます。取得条件が同じで取得中なら、無変更の適用で再接続しません。

保存中は編集とOK／適用を停止しますが、キャンセル・×・Escで画面を閉じられます。提出した保存は継続し、成功後に反映します。閉じた後に保存が失敗した場合は通知に残り、次回の設定画面は最後に成功した設定から開きます。保存完了までは設定を開き直せません。

接続・切替中にも、保存処理が終われば未接続や別機器を適用できます。新しく保存した反映先一件だけを採用し、既に開始した機器の解放を確認してから切り替えます。終了未確認なら新しい取得は開始しません。

実行中断は主画面で行います。設定・通知詳細は保存や接続処理中にも閉じられます。閉じる操作は実行を中断せず、キャンセルは未提出の編集だけを破棄します。提出済みの保存・接続適用は、中断後も継続します。接続が完了しても停止した入力は再開しません。アプリ終了では未開始の接続を開始せず、開始済み接続を回収します。

### アプリ終了

主画面の×はアプリ終了です。未提出の編集があれば「保存」「破棄」「取消し」を選べます。進行中の保存がある場合は結果を待ち、成功しても新しい映像接続を開始せず終了します。保存失敗時は画面を維持し、再保存または破棄して終了できます。終了確定後は設定・Codex・映像の処理と資源解放を確認します。

## エラーが出たとき

主画面に短い失敗通知を表示します。「詳細…」または「表示」→「通知…」から、エラーの説明と診断を開けます。「最近の失敗」には設定・映像・入力・Codex・記録・終了の各発生元で最後の失敗を保持します。通知を閉じたり、その後の操作が成功したりしても履歴は残り、現在の接続状態とは別に扱います。

詳細は選択・コピーとスクロールができます。詳細を開いたまま別の失敗が届いても、表示中の本文を差し替えません。発生元を選び直すか、通知から開き直すと最新の内容になります。設定から開いた詳細は設定画面に付属します。詳細と設定を閉じれば主画面の中断・切断へ戻れます。詳細の開閉だけで再試行や接続を行いません。

ステータスバーは映像欄・Codex欄に対応した位置へ現在の状態を表示します。設定の未適用値や過去の通知は、現在の取得先・接続中のモデルとして表示しません。

保存に失敗しても、開いている設定の入力は残ります。保存先の問題を解消してから「適用」を再試行できます。未接続の保存が失敗した場合は映像取得も続きます。読込失敗中は編集・保存を停止し、元ファイルを上書きしません。アプリを終了してファイルや保存先の問題を修正し、再起動してください。作り直す場合も終了後にファイルを退避します。

画面を開けない起動失敗は標準エラーへ診断を出し、終了コード1を返します。通常の終了は0です。読込失敗の画面から閉じた場合も0になります。

## Python から読み書きする

```python
from dataclasses import replace

from gigas.storage.settings import default_settings_path, load_settings, save_settings

path = default_settings_path()
settings = load_settings(path)
save_settings(path, replace(settings, serial_port="COM3"))
```

`default_settings_path()` は保存先だけを返します。テストでは一時ディレクトリ内の `Path` を `load_settings()` と `save_settings()` に直接渡せます。

`load_settings()` はファイルがなければ既定値を返します。ファイルは明示的な保存時に作られます。`save_settings()` は既存の TOML を読み、既知の項目を更新します。変更しない項目とコメントを保ち、変更する文字列を空にする場合も同じ行のコメントを残します。

パスの決定、読込、検証、書込に失敗した場合は `SettingsError` を送出します。既存ファイルの構文や現在の項目が不正な場合、保存を中止してファイルを保持します。一時ファイルの後始末に失敗したときは、例外にその情報も付記します。

「接続 → 入力」からポートとプロトコルを選択できます。未接続の選択で入力を切断します。プロトコル変更時は通信速度をその既定値へ戻します。通信速度の個別変更は設定画面で行います。各機器メニューの選択は対象の接続だけへ反映します。

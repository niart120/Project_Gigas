# 映像プレビュー

WindowsのDirectShowで列挙でき、機器パスを持つキャプチャーデバイスを使います。映像の取得とプレビューを提供します。観測画像の保存、Codexへの画像送信、ゲーム操作はまだ提供しません。

## 設定

「設定…」で「一覧更新」を押し、映像機器を選びます。幅・高さ・取得FPS・表示FPSを指定して保存します。機器パスとモードの範囲は[設定](settings.md)を参照してください。名前や一覧の番号をTOMLの機器パスの代わりに指定することはできません。

## 表示の契約

プレビューは取得した最新1枚を表示します。表示が遅れた場合は途中の画像を省き、最新画像へ進みます。画像の縦横比を保ち、表示領域に収まらない方向には余白を付けます。接続が止まったときは画像を消去します。

表示のための拡縮は取得画像を書き換えません。取得時刻はPC側で画像を受け取った時刻であり、ゲーム画面が生成された時刻やキャプチャーデバイス内部の滞留時間を保証しません。

# デスクトップ画面

## 主画面の構成

| 領域 | 表示と操作 |
|---|---|
| 上部 | サイドバー開閉、設定、接続メニュー、表示メニュー |
| 左端サイドバー | Project・未所属の会話一覧、会話の選択・新規作成、Projectの登録・編集・削除 |
| 中央 | 所属と会話名、会話履歴、質問・承認、Message入力欄 |
| 右上 | 16:9の映像枠。レターボックスまたはストレッチで描画 |
| 右下 | 「目標」と「今回の作業」。Goalと現在turnのPlanを別々に表示 |
| 下部 | Codexと映像の状態。対応する領域の幅に合わせて配置 |

会話と右側領域の幅は仕切りで変更でき、サイドバーを閉じるとその幅を戻す。サイドバーの開閉だけでは選択・原稿・履歴を変えない。通知の詳細は「表示」→「通知」から再確認できる。

## 会話の選択と入力

Projectの見出しを開くと所属会話を取得し、「続きを表示」で次ページを取得する。見出しの「＋」は新規会話を選び、サイドバー下部の「＋ プロジェクト」はフォルダー登録を行う。会話の初回読込み中は候補名と「読込中」を表示し、前の本文・Goal・Planを隠す。読込み失敗時は前の表示へ戻す。

別会話へ切り替える際、原稿があれば破棄を確認する。同じ会話の再選択は原稿を保持する。保存済み履歴の追加読込みは「以前の履歴」で行い、新着本文と同じ表示領域へ追加する。

Messageは通常依頼と追加指示に共用する。送信アイコンまたは`Ctrl+Enter`で送り、Enterは改行に使う。IME変換中には送信しない。「目標」をオンにして送るとGoal作成・目的編集になる。切替だけでは送信しない。

実行中で原稿が空なら入力欄右端を中断アイコンとし、原稿があれば送信と中断を並べる。空欄の`Ctrl+Enter`を中断操作にはしない。受付成功を確認した提出原稿だけを消し、失敗・受付不明や送信後に編集した原稿は保持する。

入力欄のモデル表示からモデルと推論レベルを選ぶ。選択は次の通常turn、または設定更新を受理した後の自律turnに使う。実行中turnの値を変えず、設定ファイルの既定値にも書き戻さない。

## プロジェクトの管理

Project行の「…」は「編集」「プロジェクトを削除」の2項目を持つ。同じメニューを見出しの右クリック・キーボード操作から開ける。メニュー表示だけでは会話を切り替えない。

所在確認は一覧取得後・編集開始時・保存時に非同期で行う。フォルダー不在は名前の左の警告三角形、権限などによる確認失敗は別形状のエラーアイコンで示す。名前そのものは変えず、状態文言や説明ツールチップを常設しない。読み上げ名には状態を含める。更新有無・未完了のバッジは追加しない。

「プロジェクトを編集」には表示名、1件の絶対パスと「変更」、左下に「プロジェクトを削除」、右下に「キャンセル」「保存」を置く。空の表示名では保存できない。保存中は項目と二重保存を閉じ、閉じる操作は残す。閉じても提出済みの操作は継続し、結果は主画面へ通知する。

削除確認は保存済みの名前・絶対パスと、登録のみの削除・チャットの未所属への移動・ファイル保持を説明する。ボタンは「キャンセル」「プロジェクトを削除」の順とし、削除を赤で区別する。キャンセルを既定にしてEnter・Escで削除しない。失敗詳細は通知から再確認でき、確認ダイアログで停止・切断を妨げない。

データへの作用と復旧は[プロジェクト管理仕様](../functions/projects.md)に従う。

## 会話・活動・計画の表示

以下は実装済みの表示仕様。検証条件と確認範囲・制約は、[活動記録の表示改善の完了資料](../../../spec/complete/unit_082/ACTIVITY_DISPLAY.md)を参照する。

会話は一つの選択・コピー可能な文書として表示する。Codexの本文はQt標準Markdownで描画し、見出し・強調・リスト・引用・コード・リンク・表を扱う。H1・H2は本文の1.15倍、H3〜H6は本文と同じ大きさの太字とし、見出し階層は保持する。ユーザー文、質問・承認、Plan、活動詳細はプレーンテキスト。HTMLを解釈せず、画像資源を自動取得しない。HTTP／HTTPSリンクはクリック時だけ外部ブラウザへ渡す。

更新時は選択範囲と閲覧位置を維持し、選択なしで末尾を見ている場合にだけ新着へ追従する。確定本文で選択対象の文字が削除された場合は残る位置へ寄せる。折り畳みや非表示にした詳細は選択・コピー対象へ含めない。

| 種別 | 現在の表示内容 |
|---|---|
| あなた・Codex | 提出本文と受信本文。commentaryは青系の「Codex · 進捗」、partial_answer／final_answerは紫系の「Codex · 回答」と左線。未知・欠落phaseは通常色のCodex。暗いテーマでは線・ラベルを明るくする |
| 推論要約 | 全文は会話内の折り畳みから参照。右側には最新区分の末尾3行を表示。設定OFFでは両方を隠す |
| 活動 | コマンド、ファイル変更、MCP呼出し、Web検索を活動名・短い対象・公開状態で表示。行を選ぶと全文・作業場所・終了コード・公開された引数や結果を展開する |
| 質問・承認 | 会話本文内の要求と、その直下の回答操作部。失効後は文面を残して操作を閉じる |
| Plan | 現在turnは右下、終了したturnの受信済みPlanは会話内へ残す |

MCP活動にはテキスト結果やエラーを表示し、画像結果を会話表示から複製保存しない。ライブ更新と保存履歴はthread・turn・item・表示種別で対応付ける。過去の履歴は取得できた文面を表示し、質問・承認の回答操作を再生成しない。

表示データはphase、index付きの公開要約、活動の引数・結果を保持する。履歴の追加取得は同じキーのライブ本文・表示データを上書きせず、推論を非表示にしても保持したデータは失わない。活動の失敗・拒否は閉じた行でも表示し、存在しない結果や状態を補わない。展開状態は同一itemの更新で維持し、会話切替で解除する。折り畳みは情報保護やマスキングではない。

「目標」は目的と公開状態を表示し、「再開」「削除」を置く。「今回の作業」は公開Planの手順順序と状態を示し、進行中の手順を強調する。中断・turn終了時は強調を外し、未完の手順を完了へ書き換えない。操作の意味は[会話機能](../functions/conversations.md)に従う。

その下の「推論」は公開要約の最新item・最新の本文があるindexを表示する。同じ区分へ追記し、新区分の境界通知だけでは空にしない。長文では末尾を追い、受信済みの文を順番待ちで再生しない。終了・中断後は最後の本文と終了状態を残し、次turn・会話切替で消す。公開要約がない場合は空欄。ツール開始やGoalの状態だけで本文を置き換えない。Planは自身の領域でスクロールし、推論欄の高さは本文の長さで変えない。

受信原文は即時に保持し、Markdown解析を50ms基準でまとめる。専用ワーカー1本で変更した応答の全文を解析し、GUI文書へ変わった範囲を反映する。多数の解析結果は約8msの処理ごとにGUIイベントループへ制御を戻す。一つの応答の反映を途中で分割する時間保証ではない。完了本文・会話切替より古い解析結果は適用しない。質問・承認・停止の操作は解析完了を待たない。

## 設定と接続

「設定」または`Ctrl+,`で開く設定画面には「一般」「I/O」「Codex」を置く。一般は設定ファイルの場所と表示設定、I/Oは映像取得と入力機器、Codexは接続・認証・Windows実行環境・利用状況・実行設定を扱う。具体的な値と適用時期は[設定ガイド](../../guides/settings.md)を参照。

ログイン・実行環境の準備・接続は、設定値の保存とは独立して進む。設定画面をキャンセルしても提出済みの処理は継続する。保存中や失敗後も画面を閉じ、主画面の中断・切断へ戻れる。

利用状況は期間・残利用割合・リセット日時を表示する。送信可否は実際のサーバー応答に従い、表示された残量だけで停止しない。

## 手動コントローラ

「表示」→「コントローラ」で非モーダルの小窓を開く。再選択では同じ小窓を前面に出し、閉じてもアプリ内で位置を保持する。小窓の開閉は接続やエージェントの実行を開始・停止しない。

ボタンはマウスの押下中だけ保持し、スティックはドラッグ、十字キーは8方向で操作する。マウスを離す、閉じる、最小化、別ウィンドウへの切替で手動押下を解除する。エージェント実行中は操作部を無効にする。

表示・送信できる入力は接続プロトコルに従う。3DSでは中央をSELECT/STARTに替え、LS・RS・撮影を無効にする。入力の失敗は主画面の通知で確認する。

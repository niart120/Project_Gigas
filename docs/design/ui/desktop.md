# デスクトップ画面

## 主画面の構成

| 領域 | 表示と操作 |
|---|---|
| 上部 | サイドバー開閉、設定、接続メニュー、表示メニュー |
| 左端サイドバー | Project・未所属の会話一覧、会話の選択・新規作成、Projectの登録 |
| 中央 | 所属と会話名、会話履歴、質問・承認、Message入力欄 |
| 右上 | 16:9の映像枠。レターボックスまたはストレッチで描画 |
| 右下 | 「目標」と「今回の作業」。Goalと現在turnのPlanを別々に表示 |
| 下部 | Codexと映像の状態。対応する領域の幅に合わせて配置 |

会話と右側領域の幅は仕切りで変更でき、サイドバーを閉じるとその幅を戻す。サイドバーの開閉だけでは選択・原稿・履歴を変えない。通知の詳細は「表示」→「通知」から再確認できる。

## 会話の選択と入力

Projectの見出しを開くと所属会話を取得し、「続きを表示」で次ページを取得する。見出しの「＋」は新規会話を選び、サイドバー下部の「＋ プロジェクト」はフォルダー登録を行う。会話の初回読込み中は候補名と「読込中」を表示し、前の本文・Goal・Planを隠す。読込み失敗時は前の表示へ戻す。

別会話へ切り替える際、原稿があれば破棄を確認する。同じ会話の再選択は原稿を保持する。保存済み履歴の追加読込みは「以前の履歴」で行い、新着本文と同じ表示領域へ追加する。

Messageは通常依頼と追加指示に共用する。送信アイコンまたは`Ctrl+Enter`で送り、Enterは改行に使う。IME変換中には送信しない。「目標」をオンにして送るとGoal作成・目的編集になる。切替だけでは送信しない。

実行中で原稿が空なら入力欄右端を中断アイコンとし、原稿があれば送信と中断を並べる。空欄の`Ctrl+Enter`を中断操作にはしない。受付成功を確認した提出原稿だけを消し、失敗・受付不明や送信後に編集した原稿は保持する。

入力欄のモデル表示からモデルと推論レベルを選ぶ。選択は次の通常turn、または設定更新を受理した後の自律turnに使う。実行中turnの値を変えず、設定ファイルの既定値にも書き戻さない。

## 会話・活動・計画の表示

会話は一つの選択・コピー可能な文書として表示する。本文をHTMLやMarkdownとして解釈せず、受信文字列と役割の見出しを描画する。更新時は選択範囲と閲覧位置を維持し、選択なしで末尾を見ている場合にだけ新着へ追従する。

| 種別 | 現在の表示内容 |
|---|---|
| あなた・Codex | 提出本文、受信した本文と途中の更新 |
| reasoning | 公開された推論要約。設定で非表示にでき、非表示中は選択・コピー対象にも含めない |
| activity | コマンド、ファイル変更、MCP呼出し、Web検索の公開情報。種類別の見出し・状態・詳細を文字列へ整形 |
| 質問・承認 | 会話本文内の要求と、その直下の回答操作部。失効後は文面を残して操作を閉じる |
| Plan | 現在turnは右下、終了したturnの受信済みPlanは会話内へ残す |

MCP活動にはテキスト結果やエラーを表示し、画像結果を会話表示から複製保存しない。ライブ更新と保存履歴はthread・turn・item・表示種別で対応付ける。過去の履歴は取得できた文面を表示し、質問・承認の回答操作を再生成しない。

「目標」は目的と公開状態を表示し、「再開」「削除」を置く。「今回の作業」は公開Planの手順順序と状態を示し、進行中の手順を強調する。中断・turn終了時は強調を外し、未完の手順を完了へ書き換えない。操作の意味は[会話機能](../functions/conversations.md)に従う。

## 設定と接続

「設定」または`Ctrl+,`で開く設定画面には「一般」「I/O」「Codex」を置く。一般は設定ファイルの場所と表示設定、I/Oは映像取得と入力機器、Codexは接続・認証・Windows実行環境・利用状況・実行設定を扱う。具体的な値と適用時期は[設定ガイド](../../guides/settings.md)を参照。

ログイン・実行環境の準備・接続は、設定値の保存とは独立して進む。設定画面をキャンセルしても提出済みの処理は継続する。保存中や失敗後も画面を閉じ、主画面の中断・切断へ戻れる。

利用状況は期間・残利用割合・リセット日時を表示する。送信可否は実際のサーバー応答に従い、表示された残量だけで停止しない。

## 手動コントローラ

「表示」→「コントローラ」で非モーダルの小窓を開く。再選択では同じ小窓を前面に出し、閉じてもアプリ内で位置を保持する。小窓の開閉は接続やエージェントの実行を開始・停止しない。

ボタンはマウスの押下中だけ保持し、スティックはドラッグ、十字キーは8方向で操作する。マウスを離す、閉じる、最小化、別ウィンドウへの切替で手動押下を解除する。エージェント実行中は操作部を無効にする。

表示・送信できる入力は接続プロトコルに従う。3DSでは中央をSELECT/STARTに替え、LS・RS・撮影を無効にする。入力の失敗は主画面の通知で確認する。

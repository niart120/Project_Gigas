# プロジェクトの編集・削除

ProjectはCodex App Serverの登録情報であり、表示名と1件の絶対パスを持つ。GUIから表示名・フォルダーの変更と登録削除を行う。GIGAS独自のProject台帳や更新進捗ファイルは持たず、公開APIの現在値を正本とする。

## 編集と受付

表示名は前後の空白を除き、空なら保存できない。フォルダーは既存の1件を選び直す。旧フォルダーがなくても編集・削除・履歴閲覧を受け付ける。名前だけの変更にはフォルダー・モデル・Windows実行環境の準備を要求せず、追従済みチャットを再読込みしない。

フォルダー変更では選択先が存在するディレクトリであることを確認する。同じパスはWindowsのパス比較規則で扱う。フォルダーやファイルは作成・移動しない。書込み範囲は次の明示実行で別途確認する。

実行・送信・回答配送・停止・入力回収・会話切替の途中では管理更新を受け付けない。保存中も停止・切断・終了を受け付け、二重保存と会話の新規開始・切替を閉じる。管理操作だけでチャットを切り替えたり、原稿・表示済み本文を破棄したりしない。

## フォルダー変更と既存チャット

所属する通常チャットを同じID・履歴・所属のまま新しい作業場所へ揃える。Goalの目的・予算・累積利用量を保持し、自動で再開・削除しない。アーカイブ済みチャットは旧作業場所を保持し、復元時に所属プロジェクトの現在のフォルダーに揃える。復元前にプロジェクト登録が削除された場合は、保存済みの作業場所を保持して未所属へ戻る。

更新は次の順で行う。

1. 編集開始時のID・保存値を現在の登録と照合し、通常・アーカイブ済みの所属一覧を全ページ取得する。通常チャットの公開状態とGoalを調べ、実行中・active Goalを含む場合は書込み前に拒否する。
2. 旧購読、MCP受付、保存待ち、writerを既存の所有者で回収する。解放に失敗したら登録を変更しない。
3. `project/update`で名前・rootを保存する。通常チャットを順に購読解除し、同じIDの`thread/resume`へ新しい`cwd`・`runtimeWorkspaceRoots`を渡す。管理読込みは読取り専用・通信なし・外部MCP無効で行い、結果を確認して購読を解除する。モデルへの本文やダミーturnは送らない。
4. 登録と全所属一覧を再取得し、名前・root・所属ID・通常チャットの`cwd`を確認する。選択対象と見出しを更新して完了とする。次の明示実行は新しいMCP・writerを準備し、通常の書込み範囲を検証する。

読込み済みの`thread/resume`はパス変更を無視するため、購読を先に解除する。`thread/settings/update`直後の履歴取得が旧cwdを返す経路を保存完了の判定には使わない。

ファイルは旧フォルダーに残す。新しい記録先は`新フォルダー/records/<同じthread-id>/`。存在すれば追記し、なければ作成する。攻略資料・画像・旧記録の移動や結合、本文中の旧パスの書換え、欠落した旧フォルダーの再作成は行わない。

## 途中失敗と再試行

登録と複数チャットの更新を一括確定できるとは扱わない。更新済みの情報を自動で戻さず、サーバーの現在値を読み直して登録rootへ揃える。結果不明の書込みを自動再送しない。

| 失敗箇所 | 結果と復旧 |
|---|---|
| 事前取得・検査・旧資源の回収 | 登録変更を送らない。原稿と履歴を保持し、解放済み資源は次の明示実行で作り直す |
| 登録更新・チャット更新・最終確認 | 確認済み件数と未確認対象を通知し、提出済みの更新は保持する。管理読込みの残存を避けるため接続を終了し、再接続・再取得を求める |
| 停止・切断・終了 | 完了とは扱わず、要求と資源を回収する。古い接続の遅着結果を新しい接続へ適用しない |
| 再取得に失敗 | 空一覧や成功へ置き換えず、再取得を求める |

再接続後も、実行・新規チャット開始前に登録と通常チャット全件を確認する。cwdの不一致があれば、新旧のどちらでも実行を再開せず、編集を開き直して現在の登録フォルダーのまま保存を再試行する。既に一致したチャットは再更新しない。未完了の間は別フォルダーへの再変更を拒否し、閲覧・再試行・削除を受け付ける。更新有無や未完了を示す一覧バッジは設けない。

他クライアントによる登録・所属・作業場所の変更を検出したら、編集を開き直すよう求める。公開APIにない複数クライアント間の排他・原子性は保証しない。

## 登録削除

保存済みの名前・絶対パスを確認し、保存済みIDへ`project/delete`を1回送る。編集画面の未保存値は確認対象に使わない。要求前に旧実行資源を回収し、確認できなければ削除しない。

削除するのはProject登録だけ。フォルダー・資料・記録・チャット・Goalは削除しない。所属チャットは未所属になり、各チャットの保存済みcwdを保持する。選択中の既存チャットは同じID・本文・原稿を維持し、未開始のチャットも原稿を保って未所属へ変える。フォルダー欠落・チャット0件・追従未完了でも削除できる。

公開一覧を全ページ取得し、対象IDがないと確認してから一覧から除く。応答欠落・既に削除済みの場合も再取得だけで確認し、削除を自動再送しない。取得失敗を削除済みと扱わず、復元できない「元に戻す」は設けない。

追従未完了のまま削除しても、チャット間のcwd不一致は修復されない。cwdが欠落した未所属チャットは閲覧できるが実行できない。

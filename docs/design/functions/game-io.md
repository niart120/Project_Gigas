# 映像観測とゲーム操作

GIGASは、一つのキャプチャー接続からプレビューとエージェント向け観測を供給する。ゲームへの入力は同じ入力サービスを使い、エージェントの操作列と利用者の手動操作を切り替える。

## プレビューと観測

| 用途 | 画像の選び方・加工 |
|---|---|
| プレビュー | 取得済みの最新1枚を、表示FPSを上限に描画する。描画が遅れた場合は途中の画像を省く |
| 観測のみ | 要求時点の最新キャッシュを1枚採用し、観測用の解像度でPNGにする |
| 操作後の観測 | 操作列が完了した後、観測のみと同じ経路で最新キャッシュを採用する |

取得FPS・取得解像度は機器への要求、表示FPSはGUI更新の上限である。取得画像をプレビューへ合わせて拡縮しても、観測用の画像は変わらない。観測用の解像度は別に設定する。

観測は既存の取得サービスを読み取り、機器の開始や再接続を行わない。新しいフレームの到着を待たないため、続けて観測すると同じ取得画像を返すことがある。操作後の観測も、入力がゲーム画面へ反映されたことを自動判定する機能ではない。

有効な取得状態と画像がそろっていなければ観測は失敗する。プレビューは切断・取得失敗時に画像を消去する。取得先・取得FPS・要求解像度を変える場合は旧取得を終了してから接続し直すが、表示FPSや観測用解像度だけの変更では再接続しない。

MCPでの画像取得時に暗転するかどうかは調査事項である。現在の経路だけから発生や原因を確定しない。調査と改善の優先度は[開発計画](../../roadmap.md)で扱う。

## エージェントからの入力

`observe` は現在画面、`act_and_observe` は操作列の終了結果を返す。途中画像をまとめて確認するときは撮影間隔を指定する。途中で判断を変える場合は `dispatch` で開始し、`poll` で進捗と画面を確認し、`cancel` で中止できる。どちらの実行方法でも連続する押下は次の入力状態へ直接切り替える。待機に入るときと列の終了時には全解除する。

入力サービスは同時に一つの操作を受け付ける。機器への適合を列全体について確認してから開始する。受付前に拒否した操作は入力・観測・操作記録を行わない。

入力が完了した場合に事後観測へ進む。入力に失敗した場合や中断した場合は、その結果を返す。入力後に観測だけが失敗しても、完了済みの入力を失敗へ書き換えない。

入力結果は送信処理と中断・解除の状況を表す。ゲーム内の成功や、機器が中立状態を受信したことは、画像や実機側での確認とは別である。具体的な操作形式・対応機器は[入力API](../interfaces/input-api.md)、MCP応答は[ゲームMCP](../interfaces/observation-mcp.md)を参照。

## 手動操作

仮想コントローラから、接続した入力機器へボタンとスティックの状態を送れる。Codexに接続していなくても利用でき、手動操作のための会話や記録先は作らない。

エージェントの実行中、activeなGoalの継続中、停止処理中、機器切替中、アプリ終了処理中は手動入力を受け付けない。新しい依頼やGoalの実行を始める際は、先に手動入力を解除する。解除に失敗した場合は実行を始めず、エラーを伝える。

コントローラの小窓を閉じると手動入力を解除するが、エージェントの実行や入力機器の接続は維持する。操作部の配置と利用手順は[画面・操作仕様](../ui/desktop.md)と[Codex操作ガイド](../../guides/codex.md)を参照。

## 停止・切断・終了

共通停止は、エージェントの実行中断と入力の取消し・解除を行う。操作列の残りやゲーム内の区切り、記録の保存完了を待ってから停止する方式ではない。停止の完了後は、利用者が手動操作や明示的な再開を行える。

Codexの切断と入力機器の切断は別であり、Codexを切断しても手動操作用の入力接続は維持する。アプリ終了時は、入力の解除と機器接続の終了、観測画像の符号化・保存の回収を行う。共通停止によってゲーム自体の時間が止まるわけではない。

## 実装の入口

- [プレビュー制御](../../../src/gigas/app/video.py)と[観測サービス](../../../src/gigas/services/observation.py): 同じ取得元の読み取りと表示・PNG変換。
- [操作と観測の結合](../../../src/gigas/services/_game_io_tools.py)と[入力サービス](../../../src/gigas/services/input.py): 受付、操作、結果、解除。
- [アプリサービス](../../../src/gigas/services/application.py): 手動入力とエージェント実行の調整。

取得方式・画像条件の詳細は[映像API](../interfaces/video-api.md)、設定・操作手順は[映像ガイド](../../guides/video.md)を参照。

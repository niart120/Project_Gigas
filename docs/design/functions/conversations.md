# 会話・継続攻略・停止と再開

## 会話と作業場所

Projectは攻略資料を共有する一つの作業フォルダーを表す。会話はCodex App Serverが管理する永続threadで、Projectへの所属または未所属を持つ。Goalはその会話で取り組む継続目標であり、Projectやゲームのセーブデータとは別のものとして扱う。

| 操作 | 現在の動作 |
|---|---|
| Projectを登録・選択する | フォルダーをCodexへ登録し、そのProjectの新規会話を選ぶ |
| 新規会話を選ぶ | 所属だけを保持する。初回の明示実行でthreadを作る |
| 未所属で開始する | アプリデータ配下の`unassigned/<workspace-id>/`を作業場所として作る |
| 保存済み会話を選ぶ | 所属・履歴・Goalを読み出して表示する。選択だけでは実行しない |
| 保存済み会話で実行する | 保存された作業場所と同じthreadを再開し、現在のゲーム画面を利用する |

会話を切り替えられるのは、実行・送信・停止・入力回収が終わっているとき。閲覧中の保存Goalがactiveであることだけでは、GIGASが実行しているとは扱わない。切替先の初回読込みが失敗した場合は元の選択を保つ。

会話履歴と標準自動記憶はCodexが管理する。攻略資料は作業フォルダーで利用者とCodexが編集し、ゲームI/O記録はその下の会話別領域へ保存する。再開時に作業フォルダーがなくなっていれば実行は失敗するが、保存履歴は閲覧できる。

## 通常の依頼と追加指示

通常の依頼と実行途中の追加指示は、どちらも同じ送信操作で提出する。現在のturnへの介入か、新しいturnの開始かはApp Serverが判断する。追加指示だけでゲーム入力を止めることはない。

初回実行では作業場所・ゲームMCP・記録先を準備する。同じ会話を実行中は、これらを再利用する。通常の依頼でもゲームを操作でき、Goalの作成を前提にしない。

質問への回答・承認は、該当する要求に対して送る。要求は回答済み、turn終端、停止、切断などで失効する。履歴に表示された過去の質問へは回答できない。

## Goalによる継続

Goalの目的と公開状態はApp Serverが管理し、複数turnにわたる実行を進める。GIGASは公開された更新を表示する。

| 操作 | 目的・状態への作用 |
|---|---|
| Goalなしで目的を送信 | 目的を持つactiveなGoalを作成する |
| 既存Goalの目的を送信 | 目的を更新し、状態・予算・累積利用量を維持する |
| 再開 | 保持する目的・予算・累積利用量のままactiveを要求する |
| 削除 | 目的を取り下げる。実行中のturnやゲーム入力は中断しない |

再開できる公開状態はpaused、blocked、usageLimited、budgetLimited。activeまたはcompleteは再開対象にしない。completeの目的を書き換えても新しいGoalとして開始せず、別のGoalは削除後に作成する。利用制限中の再開が拒否された場合は、公開された状態を維持する。

Goalの状態変化、turnの自然終了、質問待ちだけではゲーム入力の取消しを行わない。即時に止めたいときは共通停止を使う。

## 共通停止と手動操作

共通停止は、入力列の取消し・押下解除と、実行中turnの中断を進める。activeなGoalは目的を保持してpausedにし、既に非activeならその状態を保つ。送信前の処理を取り消し、提出済みの要求は結果を回収する。停止中に始まった自律turnも中断対象となる。

停止が完了すると通常の依頼や手動操作を受け付ける。Goalによる継続は、明示的な再開を要する。停止はゲーム自体の時間停止やゲーム内セーブを意味しない。

手動コントローラは入力機器が利用可能ならCodex未接続でも使える。エージェントの実行準備・turn・activeなGoal・停止処理中は手動入力を受け付けない。実行を始める操作では、先に手動の押下を解除する。ロード済み会話のGoal目的編集・削除やモデル変更だけでは、手動押下を解除しない。

## 切断と後からの再開

Codexの切断は、その接続の実行・MCP受付・保存処理を回収する。入力機器の接続は維持し、アプリ終了時に閉じる。会話・攻略資料・ゲームI/O記録は残す。

保存済み会話への明示送信、Goal作成・編集・再開でthreadを再開する。activeな保存Goalは、追加本文を送るより先に実行を始めることがある。閲覧中のGoal削除はthreadを再開せずに行う。

再開要求を送った後に応答や設定を確認できなかった場合は、切断・再接続してから再試行する。結果不明の本文やゲーム操作を自動再送しない。入力解除だけの失敗は機器の再接続で扱い、サーバー側停止を確認できない失敗ではCodex接続を終了する。
